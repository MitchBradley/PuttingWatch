Run the CPU at 80 MHz on the run screen

Install or reinstall with a USB cable

  1. Use Chrome or Edge on a computer. Safari, Firefox and phones can't do this.
  2. Connect the watch to the computer with its USB-C cable.
  3. Click Connect below and choose the watch from the list that pops up.
  4. Choose Install Honu Watch and follow the prompts.
  5. Keep the cable connected until it says it has finished.
This browser can't install firmware. Please use Chrome or Edge on a computer. Installing firmware needs a secure (https) page.

Only tick "Erase device" for a completely fresh start, or to fix a watch that is misbehaving — it also clears saved settings.
